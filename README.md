
# Constraint Satisfaction Lab Scheduler for Data Science Courses

A course scheduling application that uses **Constraint Satisfaction Problem (CSP)** techniques to help generate feasible timetables for Data Science courses while considering scheduling constraints.

## Features
- Automated course and lab scheduling
- Constraint-based timetable generation
- Support for reducing scheduling conflicts
- Designed for academic course scheduling

## Tech Stack
- Python
- Constraint Satisfaction Problem (CSP) techniques

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ibtj21/Constraint-Satisfaction-Lab-Scheduler-for-Data-Science-Courses.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Constraint-Satisfaction-Lab-Scheduler-for-Data-Science-Courses
   ```
3. Install the required dependencies and follow the project-specific instructions to run the application.

## Purpose

This project explores how constraint satisfaction techniques can be applied to academic scheduling, helping organize courses and laboratory sessions while respecting scheduling requirements.
